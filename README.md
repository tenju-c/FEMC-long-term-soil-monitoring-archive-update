# FEMC Long-Term Soil Monitoring Archive Update

## Project Overview
The purpose of this project is to update the FEMC soils data archive for Don Ross's soils project

## Repository Structure
- `R scripts/` — all R processing scripts, run via SoilsMaster.R
- `Input Data/` — raw input data (not tracked in Git)
- `Output data/` — processed outputs (not tracked in Git)

## How to Run
Open SoilsMaster.R and run all scripts sequentially.
